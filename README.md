# D2R Gem Crafter (暗黑破坏神 2 重制版 自动宝石合成工具)

一个专为《暗黑破坏神 2：重制版》(Diablo II: Resurrected) 打造的高效、智能、纯净的原生桌面宝石自动合成工具。

---

## ✨ 核心特性

- **🔍 智能材料页识别**：
  - 支持材料仓 5×7 矩阵（7 种宝石品类 × 5 阶品质，共 35 种宝石/骷髅）的精确识别与数量统计。
- **⚡ 自动化极速合成**：
  - **一键合成全部**：按品质顺序（碎裂 ➔ 有瑕疵 ➔ 普通 ➔ 无瑕）自动循环置入赫拉迪姆魔盒、点击转化并移回材料仓。
  - **单列定向合成**：支持单独合成指定宝石（如仅合成紫宝石至完美）。
  - **99 满仓跨阶级联流转**：当上一级宝石堆叠达到 99 上限时，自动无缝切换并继续合成下一级，魔盒内留存材料无缝复用。
  - **保留 20 颗底仓选项**：勾选后若检测到当前宝石 ≤ 20 颗，自动跳过并合成下一级，便于保留基础洗板/打孔材料。
- **🛑 原生全局紧急停止**：
  - 监听物理小键盘 **`Num 1`**（NumPad 1）热键，独立后台线程即时中断，安全防死锁与按键粘滞。
  - 具备材料不足/转化未生效的三态智能熔断机制。
- **💎 纯正暗黑暗金 UI**：
  - 搭载全部 35 种暴雪《暗黑破坏神 2：重制版》官方原版物品精灵图。
  - 物理隔离的双层卡片结构，独立居中数字显示栏，无 Emoji 纯净暗黑质感。

---

## 🛠️ 环境要求

- **操作系统**：Windows 10 / 11 (x64)
- **Python 版本**：Python 3.10+ (推荐 Python 3.11 / 3.12)
- **游戏设置建议**：
  - 游戏内界面缩放与分辨率建议为 2560×1440 或标准 16:9。
  - 合成时请打开个人储藏箱的**材料页**并保证**赫拉迪姆魔盒**位于背包装备栏中。

## 🚀 快速开始

### 1. 克隆代码仓库
```bash
git clone https://github.com/YOUR_USERNAME/D2R-Gem-Crafter.git
cd D2R-Gem-Crafter
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 运行程序
```bash
python main.py
```

---

## 📦 打包为独立 EXE

项目内置了 PyInstaller 配置文件，可直接打包为免 Python 环境的可执行程序：

```bash
pip install pyinstaller
pyinstaller -y D2R_Gem_Crafter.spec
```
打包生成的可执行文件位于 `dist/D2R_Gem_Crafter/D2R_Gem_Crafter.exe`。

## ⌨️ 快捷键与操作指南

| 功能 | 操作方式 | 说明 |
| :--- | :--- | :--- |
| **一键合成全部** | 点击主界面【一键合成全部】按钮 | 依次合成所有选中的宝石品类 |
| **单列快速合成** | 点击对应宝石列底部的【合成】按钮 | 仅合成该列宝石至完美等级 |
| **紧急停止** | 按下小键盘 **`Num 1`** 或点击【停止】 | 立即中止所有鼠标模拟与合成流程 |
| **保留 20 颗底仓** | 勾选主界面【保留 20 颗宝石】复选框 | 当前品类 ≤20 时自动流转至下一级 |
| **手动微调数量** | 双击宝石图标卡片 | 在离线或调试时可手动输入数量 |

## 📂 项目结构

```text
D2R-Gem-Crafter/
├── assets/                  # 资源文件 (35种暴雪原版宝石与骷髅PNG素材)
│   └── gems/
├── core/                    # 核心逻辑模块
│   ├── config.py            # 宝石坐标、品阶映射与配置
│   ├── recognizer.py        # 材料页识别与图像处理
│   ├── synthesizer.py       # 自动化合成控制器 (99满仓流转/保留20/转化逻辑)
│   ├── hotkey_listener.py   # Windows 原生 NumPad 1 独立线程监听
│   └── window_manager.py    # D2R 窗口定位与输入模拟
├── ui/                      # 界面模块 (PySide6)
│   ├── main_window.py       # 主窗口、日志流与控制栏
│   ├── gem_grid_widget.py   # 5x7 宝石矩阵与卡片组件
│   └── styles.py            # 暗黑风格暗金配色与 QSS 样式表
├── D2R_Gem_Crafter.spec     # PyInstaller 打包规范
├── main.py                  # 应用程序入口
├── requirements.txt         # Python 依赖清单
└── README.md                # 项目文档
```
