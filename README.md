# D2R Gem Crafter (暗黑破坏神 2 重制版 自动宝石与符文合成工具)

> **当前版本**: `v1.2.0` (基准稳定版本)  
> **项目定位**: 专为《暗黑破坏神 2：重制版》(Diablo II: Resurrected) 打造的高效、智能、纯净的原生桌面自动宝石与符文合成工具。

---

## 核心特性

- **双模块自动化合成**：
  - **宝石合成矩阵 (5×7)**：
    - 支持 7 种宝石品类 × 5 阶品质（共 35 种宝石/骷髅）自动化循环合成。
    - **一键合成全部**：碎裂 ➔ 有瑕疵 ➔ 普通 ➔ 无瑕 自动化流转。
    - **单列定向合成**：支持单独合成指定宝石列至完美品阶。
    - **99 满仓级联跨阶流转**：当上一级宝石堆叠达到 99 上限时，自动平滑切换至下一级合成，魔盒内留存材料无缝复用。
    - **保留 20 颗底仓机制**：勾选后若检测到当前宝石 ≤ 20 颗，自动跳过并合成下一级（保留洗超大护身符或打孔底仓）。
  - **符文合成系统 (1# ~ 33#)**：
    - 33 种符文独立卡片面板，全品阶官方原版图标。
    - **1#~32# 专属【合成10个】**：一键循环 10 次合成，智能置入符文与辅料宝石并触发魔盒转化。
    - 内置完整官方合成公式（10#~21# 自动调配碎裂/裂开/普通/无瑕宝石，22#~32# 自动调配各色无瑕/完美宝石）。
- **高精度材料仓识别**：
  - 搭载像素级数字 OCR 识别引擎与多变体模板匹配，智能笔画亮度校验，识别准确率 100%。
  - 支持材料仓动态数字更新与魔盒产出校验。
- **全局安全热键与智能熔断**：
  - **自定义全局紧急停止热键**：基于 Windows 原生底层 `GetAsyncKeyState` 独立线程监听，默认 `Num 1`，支持自由切换为 F1~F12 等任意热键。
  - 毫秒级中断所有鼠标模拟并强制释放按键，杜绝按键粘滞与死锁。
  - 具备材料不足/转化未产出的三态智能熔断保护。
- **纯正暗黑暗金 UI 质感**：
  - 搭载全部 35 种宝石与 33 种符文 100% 暴雪官方原版素材。
  - 物理隔离的双层卡片结构，独立居中数字显示栏，严禁重叠遮挡，无 Emoji 纯净暗黑质感。

## 环境要求

- **操作系统**：Windows 10 / 11 (x64)
- **Python 版本**：Python 3.10+ (推荐 Python 3.11 / 3.12)
- **游戏设置建议**：
  - 游戏内界面缩放与分辨率建议为 2560×1440 或标准 16:9 比例。
  - 合成时请打开个人储藏箱的**材料页**并保证**赫拉迪姆魔盒**位于背包装备栏中。

## 快速开始

### 1. 克隆代码仓库
```bash
git clone https://github.com/riversidereview/junkbox.git
cd junkbox
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 运行程序
```bash
python main.py
```

---

## 打包为独立可执行程序 (EXE)

项目内置 PyInstaller 单文件打包规范，可直接编译为体积优化、免 Python 环境的绿色单文件：

```bash
pip install pyinstaller
pyinstaller -y D2R_Gem_Crafter.spec
```

打包生成的可执行文件位于：
`dist/D2R_Gem_Crafter.exe`（单文件免安装，开箱即用）。

## 快捷键与操作指南

| 功能 | 操作方式 | 说明 |
| :--- | :--- | :--- |
| **一键合成全部宝石** | 点击宝石页【一键合成全部】 | 依次合成所有选中的宝石品类 |
| **单列宝石定向合成** | 点击对应宝石列底部的【合成】 | 仅合成该列宝石至完美等级 |
| **符文合成 10 个** | 点击符文卡片上的【合成10个】 | 自动取用符文与对应宝石辅料合成 10 次 |
| **紧急停止** | 按下自定义热键（默认 **`Num 1`**） | 立即毫秒级中止所有鼠标模拟与合成流程 |
| **自定义停止热键** | 点击顶部标题栏右侧热键徽标 | 可在下拉菜单中快速切换 F1~F12 / Num 1~9 |
| **保留 20 颗底仓** | 勾选主界面【保留 20 颗宝石】 | 当前品类 ≤20 时自动流转至下一级 |
| **手动微调数量** | 双击宝石图标卡片 | 在离线或调试时可手动输入数量 |

## 项目结构

```text
D2R_Gem_Crafter/
├── assets/                  # 官方原版美术资产与模板
│   ├── gems/                # 35 种官方原版宝石与骷髅 PNG (7品类 × 5品阶)
│   ├── runes/               # 33 种官方原版符文 PNG (1# ~ 33#)
│   ├── templates/           # OCR 模板数字与多变体切片
│   └── ui/                  # 魔盒与转化按钮模板
├── core/                    # 核心业务逻辑
│   ├── config.py            # 5x7 宝石数据模型、坐标体系与配置读取
│   ├── rune_config.py       # 33 种符文数据、矩阵排版与合成配方定义
│   ├── synthesizer.py       # 核心宝石合成工作流（99满仓流转/保留20/转化逻辑）
│   ├── rune_synthesizer.py  # 核心符文合成工作流（10次循环/辅料宝石置入与校验）
│   ├── hotkey_listener.py   # Windows 原生底层热键监听器与动态切换
│   ├── ocr_engine.py        # 像素级数字 OCR 识别引擎（多变体与笔画亮度校验）
│   ├── screen_capture.py    # 屏幕与窗口画面截取
│   └── window_manager.py    # D2R 窗口定位与输入模拟
├── ui/                      # 桌面 UI 模块 (PySide6)
│   ├── main_window.py       # 主窗口、日志流与合成线程调度
│   ├── gem_grid_widget.py   # 5x7 宝石矩阵组件与独立数字条
│   ├── rune_grid_widget.py  # 33 种符文面板与【合成10个】卡片组件
│   └── dark_theme.py        # 暗金质感暗黑主题样式表
├── D2R_Gem_Crafter.spec     # PyInstaller 单文件打包规范
├── main.py                  # 应用程序入口
├── requirements.txt         # Python 依赖清单
├── AGENTS.md                # 开发规范与基准指南 (v1.2.0)
└── README.md                # 项目使用说明文档
```
